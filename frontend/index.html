        How it works

        1. Upload a clear photo of a single plant leaf.
        2. The image is preprocessed and passed to an EfficientNetB3 model trained on the PlantVillage dataset.
        3. The model returns the predicted disease class along with a confidence score.
        4. The API enriches the prediction with symptoms, treatment steps, and prevention tips.

        Built for the Major Project — Agriculture & Intelligent Supply Chains track. Not a substitute for professional agronomic advice.
